## The entry

One line roasting the gadget used every day — the phone, and its battery
gauge that gives up at 15%:

> My phone dies at 15% battery — the only thing in my life that quits before I do.

`main.ts` (Node 22, standard library only) writes the line to `entry.txt`
in the output directory.
